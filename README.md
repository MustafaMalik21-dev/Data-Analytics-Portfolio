## 📗 Excel Projects

Interactive Excel dashboards built with Power Pivot, Power Query, pivot tables and slicers. Each project folder contains the workbook, dashboard screenshots and, where available, a data preparation log or project report.

| # | Project | Dataset | Highlights |
|---|---|---|---|
| 1 | [Retail & E-Commerce](Excel-Projects/Project%201%20-%20Retail%20%26%20E-Commerce) | Olist Brazilian E-Commerce (~100k orders) | Late deliveries averaged ~2.6 review stars vs ~4.3 for on-time orders |
| 2 | [Employee Attrition](Excel-Projects/Project%202%20-%20Employee%20Attrition) | IBM HR Analytics (1,470 employees) | Staff working overtime left at roughly 3x the rate of others |
| 3 | [Sports Analytics](Excel-Projects/Project%203%20-%20Sports%20Analytics) | Football player statistics | Player performance dashboard |
| 4 | [Energy & Electricity](Excel-Projects/Project%204%20-%20Energy%20%26%20Electricity) | Solar Power Generation Data (multi-file) | Plant output, inverter fleet health and environmental losses |
| 5 | [Road Safety Data](Excel-Projects/Project%205%20-%20Road%20Safety%20Data) | DfT STATS19 road collisions (~5 years) | Large-scale UK government data, with full project report |
| 6 | [UK Prescription Medicine](Excel-Projects/Project%206%20-%20UK%20Prescription%20Medicine) | UK prescription data | Multi-page dashboard with homepage navigation |
